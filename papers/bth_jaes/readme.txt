Journal of the Audio Engineering Society
------------------------------------------

The following files are available in jaes.zip archive:

jaes.cls    - This is the LaTeX2e class file for jaes template
Journal_of_the_Audio_Engineering_Society_JAES_template.pdf  - This is PDF file of sample LaTeX document for jaes template 
Journal_of_the_Audio_Engineering_Society_JAES_template.tex  - LaTeX document template
jaes.bib    - bibTex library used in the sample
jaes.bst    - bibTex style file used in the sample
cuted.sty   - This is the LaTeX2e style file for jaes template

Please use Journal_of_the_Audio_Engineering_Society_JAES_template.tex as the template for your JAES paper. 
Happy TeXing!!!
