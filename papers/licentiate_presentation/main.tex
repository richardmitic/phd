\subsection{Research questions}
\begin{frame}
  \frametitle{Research Questions}

  \begin{enumerate}
    \item[$RQ_1$:] How does the stereo image of a recording relate to real-world musical knowledge?
    \begin{itemize}
      \item Building a new musical instrument gave insight into what aspects of stereo field are noteworthy - (Paper I).
      \item Running existing SIP algorithms on (lost of) real music showcases what each one can detect - (Paper III)
      \item Perception of stereo image can be highly influenced by external factors - (Paper IV).
    \end{itemize}
    \item[$RQ_2$:] What methods can be used to describe the stereo image of a music recording?
    \begin{itemize}
      \item Literal answer - (Paper II).
      \item What does each algorithm \q{hear}? - (Paper III).
    \end{itemize}
  \end{enumerate}

\end{frame}
